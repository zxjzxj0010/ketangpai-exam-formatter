# 课堂派考试排版 Skill

> 把任意格式的试题（Word、文本、扫描 PDF、截图）一键排版为标准格式，输出**可直接导入课堂派等题库系统的规范文本**与**内嵌图片的 Word 试卷文档**。专为医学考试优化排版。

## 功能特性

- **八大题型全覆盖**：判断题、单选题、多选题、简答题、填空题、共用题干题（A3）、共用选项题（B）、含图片题
- **标准化排版**：题干单行、选项半角字母、题间三空行、答案全角括号、注释圆括号自动转六角括号
- **答案解析支持**：每题可附带 `答案解析：` 行，紧跟最后一个选项之后
- **图片内嵌 Word**：题干配图以 `【图片N】` 占位，最终生成真实图片内嵌的 `.docx` 文档
- **扫描件适配**：支持从扫描 PDF / 截图按彩色像素定位并裁剪题干配图，关键文字放大复核
- **格式自动校验**：内置 `validate.py` 脚本，逐行检查格式合规性，输出不合规项行号
- **批量排版提效**：内置"空挂如图"识别、全页图像块检测、答案解析批量插入等实战方法论

- Python 3.8+

## 快速开始

### 1. 安装 Skill

将本目录复制到 AI 助手的 Skill 根目录（如 `.user_skills/` 或 `.skills/`）下，保持目录名 `exam-question-formatter` 不变（或按宿主平台的 skill 命名规则调整）。

### 2. 调用方式

在对话中直接输入指令即可触发：

```
/exam-question-formatter
```

也可附带需求，例如：

```
/exam-question-formatter 原题有答案的，按照原题答案，否则自行生成答案
```

### 3. 处理流程

1. 读取题源（文本 / Word / 扫描 PDF / 截图）
2. 逐题识别题型并提取题干、答案、选项、分数、配图
3. 按规范重排为纯文本（中间格式，可直接导入题库）
4. 运行 `validate.py` 校验格式
5. 运行 `to_docx.py` 生成内嵌图片的 Word 文档并交付

## 支持题型与排版速览

| 题型 | 格式 | 说明 |
|------|------|------|
| 判断题 | `题干。(对/错)[分数]` | 答案半角括号，不写 `[判断题]` 标识 |
| 单选题 | `题干（　X　）[单选题][分数]` | 答案全角括号，字母前后各留全角空格 |
| 多选题 | `题干（　ABC　）[多选题] [分数]` | 同单选，`[多选题]` 与分数间留半角空格 |
| 简答题 | `题干。[简答题][分数]` | 题干末尾加句号，无选项 |
| 填空题 | `题干，{答案1}，{答案2} [填空题]` | 答案用半角花括号嵌入题干 |
| A3 共用题干 | `（1～N题共用题干）` + 每小主题干+子题干+选项 | 每小题完整独立排版 |
| B 共用选项 | `（1～N题共用备选答案）` + 每小子题干+完整备选答案 | 备选答案随每个小题完整重复 |

**核心规则**：题干单行、选项之间不空行、题间恰好三个空行、注释圆括号一律改六角括号 `〔〕`、答案解析紧跟最后选项后不空行、图片用 `【图片N】` 占位。

## 脚本使用

### 格式校验

```bash
python3 scripts/validate.py 规范文本.txt
```

通过则输出 `格式校验通过，未发现问题。`；不合规则输出行号与原因。

### 生成 Word 文档

```bash
python3 scripts/to_docx.py 规范文本.txt 输出.docx --images-dir 图片目录
```

可选参数：

- `--images-dir <目录>`：存放 `图片N.png` 的目录（缺省 `./images`）
- `--image-width <英寸>`：图片最大嵌入宽度，默认 3 英寸（大图防撑版）

图片目录缺图时，脚本会保留 `【图片N】` 占位符文本并输出警告。

### 自动化核对（推荐）

```bash
# python-docx 回读：内联图片数应等于【图片N】占位数
# LibreOffice 渲染核对版式
soffice --headless --convert-to pdf 输出.docx
```

## 扫描题库实战经验

处理整本扫描题库（600+ 题）时，以下要点可大幅节省人工核查：

- **"空挂如图"是常态**：题干印"（如图）"不代表必有配图，先做全页图像块检测批量定位，再与标注对照，多余标注直接判定为模板残留文字
- **灰度线条示意图是检测盲区**：纯线条图深色密度仅 3%～5%，需对疑似题号行窗口放大目视确认
- **图可能位于题号行上方或页面右侧**：块检测无 x 信息，裁剪前用题号定位确认归属
- **配图编号先规划后裁剪**：完整检测后再统一编号，避免中途补图导致批量重命名

详见 [SKILL.md](SKILL.md)「批量扫描题库提效要点（实战经验）」小节。
